# 原生离线可靠性验收

状态：待设备执行。宿主机模拟与进程故障注入已覆盖主要数据路径，不代表以下项目已通过。地图策略已接入本机共用核心，本验收覆盖其与规则、记分的组合；真实GPS、原生语音和地图实地可靠性仍需独立验证。

## 执行记录

记录手机型号、系统、应用构建版本、可用空间和是否有离线语音资源；分别记录冷恢复与热记分耗时。语音需另测识别结束到首个有用反馈、完整播报；不能以存储耗时代替。

## 断网

1. 联网登录，选球场、Tee，准备离线记分，确认已激活。
2. 打开飞行模式并关闭Wi-Fi。用按钮或文字完成18洞；含正常击球、OB回原位、暂定球、水障碍红/黄桩救济、记分更正和结束确认。
3. 每次确认后核对逐杆、罚杆和推杆；本机“读取保存状态”应可用。无离线语音模型时，文字/按钮仍可完成记分。
4. 在每个有可靠球位的球洞询问“这杆怎么打”“有没有保守方案”，核对本机给出候选且不发网络请求；缺球位或地图时应明确补问。
5. 在断网状态尝试同步，预期失败但记录不丢失，之后仍可继续记分。
6. 恢复网络同步，对比本机与后台逐杆和每洞总分；再次同步不得重复增加击球或罚杆。

## 操作系统终止进程

1. 在发球选杆后、击球后、救济未完成时、成绩待确认时、成绩已确认时分别强制终止应用，重新打开并选择“恢复本机离线球局”。
2. 检查球洞、选杆、事故处理阶段、待确认成绩和已确认成绩与最后成功保存时一致；不得把重启当作新击球。
3. 离线准备时终止进程：恢复入口应显示准备待恢复/取消；联网后处理，不能在未确认激活时记分。
4. 上传中断网/终止后重新同步；后台已提交部分不得重复计数。
5. 记录恢复失败的完整提示，保留本机数据；不要用卸载、清除应用数据来“修复”。系统强制终止与硬件断电为不同验收项。

## 存储压力

1. 在专用测试设备或模拟器上使用系统支持的空间限制方式；不要删除真实球局或个人文件来制造空间。
2. 在低空间下记录击球和确认成绩。保存失败应明确提示未确认，不能播报已保存；释放测试占用后读取本机记录，核对后再重试。
3. 校验同步回执落盘遇到空间不足时队列仍可恢复；有空间后再次同步不重复计数。
4. 多场测试后检查当前检查点数量固定，地图不随每次话语重复写入；另验证账号隔离。

通过标准：所有已确认成功保存的数据在上述操作后完整一致；不出现重复击球/罚杆，不把损坏记录静默当成更早的成绩。记录异常路径和实际耗时，未执行的项目保留“待验证”。
