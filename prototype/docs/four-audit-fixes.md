# 四项审查问题修复（2026-11-23）

当前核心1.4.0、测试数据集shared-core-4。首次问答/赛后应用服务与共用核心仍保持原来的边界，不新增第二套规则。

## 跨场散布

开始下一场时，明确允许跨场记忆的账号保留tee_dispersion_samples与tee_dispersion_summary；不保留旧球局、选杆上下文或散布去重token。关闭跨场记忆后不沿用这些数据。样本仍按原有200条上限管理，模拟数据不参与个人能力校准。

## 独立记分入口

通用/sync的kind:round创建、修改、删除和旧操作重试均返回410，拒绝发生在写入数据和回执之前。/records不再暴露旧round文档。profile、club和memory记录的已有接口继续工作；球局、逐杆、罚杆、成绩只通过共用核心写入。没有把旧独立记分数据自动导入新球局。

## 地图落点搜索

保留原有粗采样作为快速路径。根据当前Carry圆与目标区域、障碍多边形、孔洞及已标OB边界/端点的交点，额外评估粗采样之间的可用弧段；同一落区弧段已有无罚杆/沙坑样本风险且无重复历史事故权重的候选时，跳过重复细化。长杆滚上果岭时也核对2至10码滚动范围内的入口方向。

搜索仍核对实际落点、障碍飞越余量、散布与滚动通道。每个Carry最多64个方向，局部半径缓存最多96项、只存在于单次候选搜索中。没有针对凤凰山或某个洞写方向特例。

## 历史成绩基准

网页与原生同步完场时统一保存当场固定地图的18洞标准杆、公布长度。基准作为账号隔离的只读组件保存：相同配置去重，普通聊天和历史目录读取不加载基准内容。

只有同球场、同Tee、完整18洞成绩，以及完整且一致的比较基准，才计算最好成绩与平均成绩对比。标准杆/长度变化、基准缺失或损坏时保留历史成绩，但不强行比较；不把当前地图倒填成旧场次基准。成绩对比仍使用全部可比历史场次，击球策略参考仍限制最近五场。
