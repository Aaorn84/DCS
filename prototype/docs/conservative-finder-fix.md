# 保守方案与其他方案的保底杆处理

2026-11-23，默认核心1.7.0、策略政策修订3。1.4/1.5/1.6冻结核心保留原规则和策略，既有球局不自动换版本；验证新策略需新开球局。

## 最终行为

四/五杆洞开球询问“保守方案”时，尚未设置保底杆就补问球杆及稳定Carry；已设置球杆但Carry缺失或仅为暂估，只补问稳定Carry。资料齐全不重复询问。

询问“其他方案”时，不把设置保底杆作为前提，直接比较已知及暂估Carry，包括长铁、球道木和铁木杆；暂估距离保留提示。两种请求在资料齐全时都优先评估保底杆，但不会因为个人信任标签忽略明显更低风险的其他候选。“其他方案”避免重复刚才的同一落点，可以比较保底杆的不同路线。

补问后回答“5号木”“200”或“5号木200码”，网页和手机均登记个人资料并按原请求继续规划，不自动选择本杆或记击球。已知但没有核对到落点时说明原因，不反复索要相同资料。只有沙坑用途而无常态Carry的挖起杆不作为开球距离候选。

原筛选只接受风险严格下降或落区额外宽3码，导致已知保底杆的有效落点被排除。现在同时比较OB、水域、历史重复失误及沙坑暴露；风险相近的替代可参与，但明确说明地图比较没有显示风险明显降低，不保证换短杆更安全。无球洞编号特判。

政策版本纳入网页持久化及手机建议缓存校验，旧政策建议失效；当前重复请求继续复用有效缓存。冻结核心内容不变。
