# v0.1.2验证报告

本版技能版本0.1.2；天气算法未修改，保持0.1.1；新增shot_evidence组件为0.1.0。旧版本验证报告保留作历史证据，不将旧包改写成新版本。

## 本轮交付

- 首次每轮只问一个信息点、等待回答、允许中断与跳过的指令。
- 开场说明可能需要五场或更多相处，以及第一场可以提供的实际价值；不承诺固定场数后精准。
- 不完整球位、杆号与击球间断的分层补采/降级规范。
- 可调用的结构化击球证据门控，拒绝把位置移动/漏杆间断当成一次击球。

新增8个数据门控测试先运行，因组件尚未实现而复现错误（含子测试共13条error）；实现后全量53个测试通过。数值、输入边界、校准及打包原有45项回归均保留。机器摘要见 [validation-result-v0.1.2.json](../assets/validation-result-v0.1.2.json)。

```sh
python3 -B -m unittest discover -s tests -p 'test_*.py' -v
```

门控测试覆盖缺起点、缺实际球杆、未确认球位、可能漏杆/救济、时间逆序、跨洞、低质量定位、不愿记录、无有效移动与正确水平总距。不会据此声明空中落地距离已知。
