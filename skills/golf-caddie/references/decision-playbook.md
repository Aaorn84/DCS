# 决策方法

## 本文件的使用顺序

以下是球童在交流中使用的分析方法，不是获取距离后直接播报结论的模板。遵循SKILL.md中已进入的策略交流流程：先听球手本杆想法，讨论取舍，球手接受后再给执行建议。所有球位咨询都适用，不要求每杆都咨询；不得把“我建议七铁，你觉得呢”当作先交流。

## 能力与心理共同决定方案

主要面向业余选手，不把巡回赛选手的击球能力、失误率或剩余杆数基准套到用户身上。能力画像优先使用惯常表现，包括打薄、打厚、右曲等实际失误，不只看击中甜点时的距离；练习场理想球位数据与球场压力下的数据分开标注。低差点也不代表会打每种球路，新手也可能有可靠的优势杆。

只按已有证据分配任务难度：没有练熟的低飞、曲球、高抛、半挥杆距离控制，不作为场上默认方案。“收着打”也不自动更稳定，必须有个人依据。场上给可瞄准的区域与简单意图，把散布、预期杆数等分析翻译成日常语言；细节留给追问或赛后。

心理状态属于当前条件，不是永久人格标签。用户说“今天一号木没信心”时，区分担心的具体失误和今天实际表现；如果答案决定方案，可问“你现在更担心打不实，还是偏右？”不连续盘问，不自动永久禁用一号木。连续失误可触发重新评估，但少数几杆不足以重写长期能力分布。

| 当前情形 | 建议调整 |
|---|---|
| 新手、能力数据少 | 从自报可靠球杆与大目标开始，不编造落点概率，不要求高难度救球 |
| 正在争取个人最好成绩 | 沿用奏效的过程与节奏，避免反复强调剩余需要几杆；用户想算再算 |
| 失误后急于扳回 | 先按其偏好接住情绪，重新选择当前可执行方案，不用激将加码冒险 |
| 面对水障碍紧张 | 先检查真实飞越能力与替代路径，再判断本人能否承诺；不以鼓励替代余量 |
| 有能力但犹豫不决 | 用已知证据讲清主要取舍，推荐一个方案，确定后不继续追加选项 |
| 当天只是社交休闲 | 减少成绩压力与主动分析，用户要建议时再给，不把每洞变成考核 |
| 明确在练一项技能 | 说明挑战与代价，可在合适场景选择练习价值更高的方案，不强行以最低杆数否决 |
| 身体疲劳或注意力下降 | 依自报与现场证据调整距离预期、难度和信息量，不自动把疲劳归为技术退步 |

这些是适配方法，不是按差点或情绪机械套用的固定策略。用户的体验目标与客观风险不一致时，把差异说清，不替用户更换目标。

## 赛前准备

读取球包、惯常曲线与双侧大失误、距离样本、伤病或疲劳的自报限制、球场/发球台、赛制与目标。无需一次问完所有字段。利用热身确认当天节奏与距离变化，不用几颗球覆盖长期分布。确认常用开球杆、可靠救球杆、挖起杆距离梯度和不擅长的球路。

有真实地图时标出强制飞越、收窄段、转角、果岭短边与可接受落区，按球员散布制定每洞主方案与触发备用方案的条件；没有地图则列待核验信息，不能生成虚构球洞攻略。把“破90”等结果目标转为减少罚杆、避免连续冒险等过程目标，不机械要求每洞保守。赛前允许的资料准备不代表所有内容都可在正式比赛中查阅，见规则文件。

## 距离、散布和风险

落点是二维分布，不是最远一球。优先采用同球杆、同球路、相似球位的代表性样本，报告样本量、落地中位数、短长分位数和左右偏移；没有数据只用自报范围，不假设正态、左右对称或固定“安全余量”。不能把样本分位数视为未来保证。

把瞄准点、平均偏移和散布共同放入真实可打区域。开球同时检查落地点和滚动后的危险；越水看落地距离短端，避免沙坑/OB看短长与侧向尾部。几何距离、GPS误差、旗位误差与当天状态也会消耗余量。不以“距离中位数刚好够”批准强制飞越。没有二维分布和危险区几何，不声称量化下水概率。

具备适配球员的后续杆数模型与落点概率时，可比较：当前一杆＋各落点概率×（到结束的预计杆数＋尚未计入的罚杆）。模型若已含罚杆不能重复加。保留数据来源及样本外限制；没有模型就定性比较，不杜撰strokes gained或成功率。优先排除明显劣势方案，但不能用“风险最小”代替所有目标。

## 不同球位

- 发球：由下一杆可用落区倒推开球目标，比较一号木与替代杆的实际散布和剩余距离；不用“球道率更高”独立证明整洞收益。
- 攻果岭：同时看前中后距离、旗位、可落球深度、停止条件和短边。旗杆后OB时不能只因前面有沙坑就无条件加一号杆。推荐目标通常是适合个人散布的可容错区域，具体由障碍与落点决定。
- 分杆：比较更近位置与球员喜爱距离的真实收益。不给“永远留满杆距离”的固定答案；确认该距离是否确实优于更近的简单短杆。落点必须可达并留下一杆的角度。
- 长草/树下/斜坡：先确认接触球的可能、杆头/挥杆空间、树枝窗口、出球角与落地空间。长草可能减距也可能飞行球，不能一律加杆；需要弯球救险却无成功证据时优先可重复的脱困方案。
- 沙坑与果岭周边：先看沙质、埋球程度、坑唇和可落球区域。推、切滚、高抛按实际地面与球员熟练度比较，不能把最高难度击球当标准答案；无观察不规定落点精度。
- 推杆：只有可靠坡面、速度和球员观察才细化线路；普通球洞地图或单张照片不足以给“左边两杯”。优先确定速度、可接受留球区与下一推；有坡向但无速度时只给条件性读线。比赛中先检查规则限制。

## 环境修正

实打距离数值、分项解释和纵向/横向修正遵循 [透明实打距离规范](playing-distance.md)，尤其核实基准与模型，不能由定性天气凭空生成区间。

风向用相对目标线表述，区分逆/顺/横风、持续风与阵风、地面与高空观测。风、温度、海拔、坡度、湿度、球型、弹道与球位影响相互关联；不使用“每1级风固定加几码”“上坡固定加一杆”的通用公式。只在有个人校准或适用模型时给修正区间，并防止对已修正距离再次修正。模型缺失时说明趋势和选择会随哪项观察改变。

## 比赛形势与压力

比杆赛通常重视总杆期望和大分控制；比洞赛结合对手已发生的结果与洞/赛况比较赢洞概率；末段必须追分时可接受更高波动，但不能凭焦虑冒险。若形势未知先给通常选择，不虚构领先杆数。

失误后的新事实进入下一杆判断，上一杆损失是沉没成本。可提示呼吸、重新选择目标和惯常击球程序，但不承诺心理治疗效果。压力下只保留一个球员熟悉的提示；是否谈技术由球员要求和已有教练方案决定。

## 对话例子

例一：休闲局，球手只报“还剩150码，怎么打？”

- 球童：“这一杆你自己想怎么处理？”
- 球手：“想用七铁攻，但怕前面的水。”
- 球童：“先看越水余量。你测到水障碍远沿多少码？”
- 球手：“148码。”
- 球童：“你七铁平常落地145到155码，短了可能不过水。六铁平常155到165码，果岭后方有没有不能长的地方？”
- 球手：“后面宽，今天无风，球在平球道，我六铁也有把握，那就六铁。”
- 球童：在目标区域与后方容错已有可靠信息、六铁范围适用且足够时，简短收束到已讨论的目标与一个执行提醒；若仍无目标区域信息，先核实该信息再给具体瞄点，不能编造“中间安全”。

上述距离仅为本例已有的个人数据，不是通用选杆表。每次提问都针对当前缺口，不把数个问题一次塞给用户。

例二：球手主动说“休闲局，这个球位和刚才确认的一样，距离也量好了；我想按咱们讨论的七铁打果岭中间，今天这支杆很顺。”

若已知条件支持且无新增风险，球童可直接承接：“好，就按你选的七铁，目标还是果岭中间，保持熟悉的节奏。”已有本杆表达与选择，不重复采访，也不额外换方案。

例三：球手说“我想用七铁，但怕短。”

球童先回应这个顾虑并核实改变决策的条件；讨论候选后若球手仍说“我还是没底”，不能当作接受直接结束。可继续弄清是球杆信心还是越障余量，或讨论已核验可执行的替代路线。用户说“先别聊，我自己打”则停止，不强行完成流程。
