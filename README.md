# 电子球童 / Golf Caddie

面向业余球手的电子球童：球场与GPS信息、语音事件归因、可回滚记分，以及用户自愿开启的伙伴与教练服务。

## 项目结构

- `skills/golf-caddie/`：Skill、状态引擎、天气算法与核心测试。
- `prototype/`：认证API、移动端原型、合成球场和GPS流程。
- `球场数据接入样本/东莞凤凰山/`：WGS84用户确认、规范化数据、适配器及10项测试。
- `demo-local/`：无前端依赖的本地文字交互演示。
- `versions.json`：各组件独立版本；不是生产上线版本。

## 完整流程演示

```sh
python3 -B demo-local/serve.py
```

打开 http://127.0.0.1:8791。可新建临时测试身份，或用固定测试账号注册/登录后恢复。同一账号从首次认识逐项问答，进入赛前、场中、结束、可选单点教练，最后开始下一场。支持“先打球，稍后了解”和“安静”。详情见技能中的complete-journey.md。

网页使用合成地图和模拟GPS、文字转写；手机App也接入同一个认证旅程API，原生前台语音待真机验收。阶段语义为确定性原型，不是完整自然语言模型；状态、记分与记忆实际持久化，不是静态聊天脚本。

## 版本管理

`main`保存已验证基线；后续改动使用`codex/`分支，经自动测试和PR审查后合入。组件分别递增版本，并更新`versions.json`及`CHANGELOG.md`。版本提交应同时包含代码、协议、测试和相应文档。已发布版本不原地替换。

目前有授权确认资料的跨场档案，但没有生产级ASR、经过统计校准的完整画像或真实GPS实地验收。凤凰山样本坐标系已由用户确认WGS84，但实际精度与边界语义仍待验证。原始设计文档、历史ZIP、个人账号数据和密钥不在本次基线范围内。

文件与目录统一使用稳定名称，不附版本号；版本信息保留在SKILL元数据、versions.json和CHANGELOG。历史构建单独归档，当前交付位于dist。

### 使用习惯

授权跨场记忆后，连续三次在有效的上一杆用杆补问中明确跳过，球童会提示可以说「以后不用问上一杆用杆」。确认关闭后可说「恢复询问上一杆用杆」。回答「不知道」不会计为跳过。

球童也可以记住过水和果岭边的打法偏好。开启跨场记忆后，可直接说「过水我通常先打到水前」或「果岭边我通常切滚」。如果希望球童从选择中学习，可以说「确认能过水也能打到水前，我选直接过水」或「确认切滚和高抛都能打，我选高抛」。最近三次不同球洞机会选择相同，球童会记下偏好。过水比较目前依靠用户确认两条路线可打。可说「忘记过水打法偏好」或「忘记果岭边打法偏好」。

还可以说「开球我通常选保守路线」或「我喜欢下一杆留90码」。比较开球路线时，球童会指出哪个候选更接近你喜欢的剩余距离，已知障碍风险优先。可以说「忘记开球打法偏好」或「忘记下一杆距离偏好」。

场中可结合现场信息使用偏好：

- 「攻果岭，短杆Carry130，长杆收挥Carry138，飞越至少132，可用落点133到145码，怎么选？」按同一单位比较飞越和落点。
- 「五杆洞第二杆怎么打？」按球位到果岭参考点倒推留距。「五杆洞第二杆，两条落点都可用，可推进160或200码，怎么选？」比较两处落点的预计剩余距离。
- 「靠边旗，旗在右侧，旗侧有足够落点且飞越有余量，怎么打？」结合偏差方向和攻旗偏好给建议。
- 「树下我通常低飞向前」「树下横向和前方都有出球窗口，两边落点可用」。
- 「长推我通常只听距离和速度」或「长推我通常也听路线」。「长推12米，下坡，球会向右偏，怎么推？」按现场描述给速度和起线方向提示。

树下窗口、旗侧落点、推进路线和推杆坡向可由球员确认。当前球场数据没有可用于自动读线的果岭坡度模型。

开启跨场记忆后，可以说「短杆实绩，起杆离旗75码，一杆后离旗5码」。同一球洞保留最近报告。一个距离区间至少有两场、三条记录后，球童可按一杆后的典型离旗距离推断留距，用于开球和五杆洞第二杆。可说「我擅长留多少码？」查看，或说「忘记短杆实绩」清除。主动设定的留距优先。

短杆实绩也可补记用杆和挥幅，例如「短杆实绩，起杆离旗75码，一杆后离旗5码，用54度杆，半挥杆」。同一组合在目标距离前后5码内有至少两场、三条记录时，球道或发球台的攻果岭建议可以参考该组合。

果岭边两种打法都可用时，可说「短杆实绩，起杆离旗15码，一杆后离旗3码，球位果岭边短草，两种打法都可用，用切滚」。也可记录抛切或高抛。问「果岭边，离旗15码，球位果岭边短草，两种打法都可用，怎么选？」可比较相近距离、同类球位的实绩。每种打法至少两场三条记录才参与比较。可用「忘记果岭边实绩」清除。

开球可报告「开球实绩，用一号木，偏右25码」或「开球实绩，用3号木，打直」，偏差相对瞄准线。每支杆至少两场三条记录时，比较路线会提示历史偏差方向与已知障碍侧是否重合。同一洞保留最近一条。可说「忘记开球实绩」清除。

可说「球位实绩，长草，用7铁，Carry135码」，也可把球位改为「球道」。每支杆在每类球位至少两场三条记录后，可问「7号铁在球道和长草的Carry多少？」查看中位数与记录范围。攻果岭时只参考当杆球位的数据。可说「忘记球位实绩」清除。

可用「飞越比较，长草，飞越至少132码，用7铁或6铁，怎么选？」比较当前球位的 Carry 实绩。球童会先核对记录中的最短 Carry。可用「长推实绩，起推12米，上坡，推短2米」记录控速。相近距离和同类坡向有足够记录时，下次会提示推短或推过的倾向。

### 手机端：只听我的声音（原生开发版）

首次登录并进入新手流程前，可选择录入三段本人语音或跳过。录入后，在球局页面点“说一句（验证声纹）”开始录音，点“结束录音”提交；录音最多七秒。已录入的用户可关闭、删除或重新录入。关闭后恢复普通前台语音，文字输入始终可用。

开发版使用 [Sherpa 端侧说话人模型](https://k2-fsa.github.io/sherpa/onnx/speaker-identification/)。首次录入从官方发行地址下载约 28 MB 模型并核对 SHA-256。每段语音在手机上先验证，通过才用系统的离线语音识别转写；不通过或无法验证时，不转写、不提交球局消息。模板按服务器和账号隔离，用本机 SecureStore 保存，不上传。短录音缓存用后清理，重新进入页面时清理残留。

需要重新构建并安装手机原生开发版；网页版不运行声纹。Android 需 13+，设备需提供中文离线语音识别。此版是前台按键模式；相似度阈值为初始值，尚需在真机上用本人、同组球友、极短口令和多人重叠说话验收。多人重叠的说话人分离尚未接入，声纹不替代账号登录。
